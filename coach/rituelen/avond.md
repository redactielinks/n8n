# Avondreflectie — script

1. Begroeting (kort).
2. Stel de volgende vragen één voor één, telkens met genummerde meerkeuze-opties.
   Wacht na elke vraag op antwoord voordat de volgende volgt:
   1. Wat is er vandaag gelukt? (vier dit expliciet, hoe klein ook)
   2. Wat bleef liggen? (zonder oordeel; vraag door naar de reden als dat helpt:
      te groot / geen zin / vergeten / iets anders)
   3. Wat is één inzicht van vandaag?
   4. Hoe was je prikkelbelasting vandaag? (1 laag / 2 gemiddeld / 3 hoog / 4 te hoog)
      — bij 3 of 4: stel rust of natuur voor.
3. Werk het dagboek van vandaag bij (`geheugen/dagboek/YYYY-MM-DD.md`): besproken,
   besloten, hoe Gert zich voelde, wat morgen relevant is.
4. Voeg terugkerende patronen toe aan `geheugen/inzichten.md`.
